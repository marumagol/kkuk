# 트립추얼 (Triptual)

가고 싶은 장소를 모아 여행을 계획하고, 기록하고, 모으는 반응형 웹앱.

- Next.js 15 (App Router), Tailwind 4, Supabase (로그인 : 이메일 6자리 코드)
- 시작 : `.env.example` 을 `.env.local` 로 복사해 Supabase 주소와 공개 키를 넣고 `npm install && npm run dev`
- 공통 조각 미리보기 : `SHOW_DEV_KIT=1` 일 때 `/dev/kit`, `/dev/screens/*`
- 기획, 디자인 문서는 프로젝트 파일(CLAUDE.md, 기획/, 디자인-가이드.md)에 있음
